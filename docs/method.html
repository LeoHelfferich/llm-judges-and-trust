Protocol

What is held fixed, and what is allowed to move

The questions, passages, and answer variants are checked in. The only thing a paid run changes is the judge’s raw response. Analysis reads that cache and can be repeated for free.

Four measurements

Self-consistency uses one rubric, one model, and three calls. Temperature is 0 when the model advertises it. GPT-5.4 Mini does not, so those calls omit the parameter. The chart is the distribution of score ranges. Prompt sensitivity rescores the same pairs with a short rubric and a two-sentence chain-of-thought rubric. Inter-judge agreement is quadratic weighted κ between models on the strict rubric’s first repeat. Planted-error misses use a threshold of 4 on a 1–5 scale: a subtly wrong answer is missed when correctness is at least 4, and an unsupported answer is missed when faithfulness is at least 4.

Because 4 means “minor error” in the rubric, the subtle-error rate is also reported at a stricter cutoff that counts only a perfect correctness of 5. One generated variant was excluded from the analysis (data/disputed.json) because it was not actually wrong: the entity swap produced “Monte Gargano”, the place of the shrine, for “Whose shrine did the pilgrims go to in 1016?”. Replies that do not parse are left out of every rate and listed by reason. Claude Haiku 4.5 sometimes returned faithfulness without correctness under the strict rubric, always with faithfulness 2.

Who judges the judges: nobody’s opinion. Each planted error is a deterministic edit of the gold answer, so the reference label is known before any model is called. Agreement and drift are computed from the cached scores by the analyzer in analysis/Analyzer.kt.

Answers

Fifty questions come from the SQuAD 1.1 development set. Thirty-two gold answers are edited by a deterministic numeric rule (a year, ordinal, decade, decimal, or integer that does not occur in the passage). Eighteen gold answers are multi-word proper names swapped with another name from the same passage. The unsupported condition keeps the gold answer and substitutes a passage from a different article that does not contain the answer or its salient numbers.

Judges

Calls go to OpenRouter with one key, OPENROUTER_API_KEY. The default set is Grok 4.3, GPT-5.4 Mini, Claude Haiku 4.5, Gemini 2.5 Flash, and Llama 3.3 70B Instruct on DeepInfra only. Prices are pinned in config/experiment.json from the public model list on 26 October 2026. A paid run refreshes that list and refuses to start when the estimate, times a 1.5 safety margin, exceeds 10 EUR. It also stops between calls if the next max-token ceiling would cross the cap. Models that advertise reasoning are asked for effort: none, because hidden reasoning tokens are billed. The code is MIT. The SQuAD subset, and every copy of its questions, answers, or passages, stays CC BY-SA 4.0. Model outputs are published for reproducibility and are not under either license.

What the dry run is

Without a key, run --dry-run fills the cache from a deterministic simulator. The simulator is deliberately uneven so the charts are not blank. Those numbers are not findings. Re-running analysis on a real cache overwrites docs/data and this site updates with it. No build step.
